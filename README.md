# نظام إدارة متجر إلكتروني متكامل (Multi-Purpose Store Platform)
### حل جاهز لأي سوبرماركت، متجر ملابس، متجر أجهزة كهربائية، أو مطعم

---

## نظرة عامة

هذا النظام عبارة عن **منصة تجارة إلكترونية متكاملة** مبنية على Laravel، مصممة لتكون **قالبًا عامًا (Generic Template)** يصلح لأي نوع من أنواع الأعمال التجارية: سوبرماركت، متجر ملابس، متجر إلكترونيات وأجهزة كهربائية، مطعم توصيل طلبات، أو أي متجر تجزئة آخر.

يتكوّن النظام من **ثلاث واجهات رئيسية** تعمل معًا بشكل متكامل عبر REST API:

| الواجهة | الوصف |
|---|---|
| 🖥️ **لوحة تحكم الإدارة (Dashboard)** | واجهة ويب كاملة لإدارة كل تفاصيل المتجر |
| 📱 **تطبيق العميل (Client App)** | واجهة API كاملة لتصفح المنتجات والشراء |
| 🚗 **تطبيق السائق (Driver App)** | واجهة API كاملة لإدارة عمليات التوصيل |

النظام **ثنائي اللغة بالكامل (عربي/إنجليزي)** على مستوى لوحة التحكم وردود الـ API، ويدعم تعدد الفروع مستقبلًا دون الحاجة لإعادة هيكلة (Multi-Branch Ready)، مع بنية مرنة تسمح بإضافة بوابات دفع وطرق تحقق جديدة بسهولة.

## 1️⃣ لوحة تحكم الإدارة (Admin Dashboard)

### أ) إعدادات المتجر العامة
- **الإعدادات العامة**: اسم المتجر (عربي/إنجليزي)، الشعار، البريد، الجوال، الواتساب، العنوان.
- **إعدادات المتجر**: نسبة الضريبة المضافة، الحد الأدنى لقيمة الطلب، وضع الصيانة (مع رسالة صيانة قابلة للتخصيص بلغتين)، رابط التطبيق على App Store وGoogle Play، رقم الإصدار الحالي، إعلان بشاشة كاملة داخل التطبيق.
- **سياسة المتجر**: نصوص وتفاصيل قابلة للتخصيص لثلاث بطاقات ثقة (الشحن المجاني، سياسة الاسترجاع، الدفع الآمن) بلغتين.
- **أيام وساعات العمل**: تفعيل/تعطيل التقيّد بأوقات دوام محددة، تحديد أيام العمل وساعة البداية والنهاية لكل يوم على حدة، ورسالة مخصصة تظهر للعميل خارج أوقات العمل.
- **إعدادات التوصيل**: تحديد موقع المتجر على الخريطة، أقصى مسافة توصيل، نوعان لتسعير التوصيل (سعر ثابت أو تسعير ديناميكي حسب شرائح مسافة قابلة للتخصيص بالكامل)، وخيار السماح بـ"الاستلام من المتجر" (Pickup) كبديل عن التوصيل.
- **إعدادات طريقة التحقق (OTP)**: اختيار طريقة إرسال أكواد التحقق (SMS / واتساب / بريد إلكتروني) مع إعدادات كل مزوّد خدمة على حدة، بالإضافة لخيار "تفعيل مباشر بدون تحقق" للتجربة والتطوير.
- **إعدادات نقاط الولاء**: تفعيل/تعطيل النظام، تحديد معدل اكتساب النقاط لكل عملية شراء، قيمة استبدال النقطة الواحدة نقدًا، والحد الأدنى للنقاط القابلة للاستبدال.

### ب) بوابات الدفع الإلكتروني
نظام دفع مرن (Plugin-Based) يدعم تفعيل/تعطيل أي بوابة بضغطة زر مع تبديل بين وضع تجريبي (Test) وحقيقي (Live)، ويشمل حاليًا:
> **HyperPay • PayTabs • Moyasar • MyFatoorah • Stripe • PayPal • Tabby (الدفع بالتقسيط) • Tamara (اشترِ الآن وادفع لاحقًا)**

كل بوابة تُدار بشكل مستقل مع تشفير كامل لبيانات الاتصال الحساسة، والتحقق من التوقيعات الرقمية للـ Webhooks لضمان الأمان.

### ج) إدارة الكتالوج (المنتجات)
- **الأقسام (Categories)**: أقسام رئيسية وفرعية غير محدودة، مع صور وسلايدر صور خاص لكل قسم.
- **العلامات التجارية (Brands)**.
- **وحدات البيع (Units)**: كيلو، قطعة، لتر... إلخ.
- **خصائص المنتج (Attributes)** بنظام مزدوج ذكي:
  - **متغيرات (Variants)** مثل المقاس واللون — تولّد تركيبات مستقلة بسعر ومخزون ورمز SKU خاص بكل تركيبة.
  - **إضافات (Modifiers)** مثل الصوصات أو الحجم الإضافي — تُضاف كسعر إضافي فوق سعر المنتج دون تعقيد الفيرنتات.
- **المنتجات**: بيانات أساسية بلغتين، وصف قصير وكامل، صور متعددة، سعر أساسي وسعر عرض بتاريخ بداية ونهاية، تتبع مخزون اختياري (يمكن جعل بعض المنتجات "غير محدودة الكمية")، تنبيه تلقائي عند اقتراب النفاد، وربط بوحدة بيع.
- **رموز الخصم (Discount Codes)**: نسبة خصم، تاريخ صلاحية، ثلاثة أنواع استخدام (مرة واحدة / متعدد / عدد محدد)، مع تقرير تفصيلي بكل عميل استخدم الكود ومتى.

### د) إدارة الطلبات
- عرض كل الطلبات مع فلاتر بحث متقدمة (رقم الطلب، اسم/جوال العميل، الحالة، التاريخ).
- تفاصيل كاملة لكل طلب: المنتجات، الكميات، الخصائص المختارة، الخصومات، الضريبة، سعر التوصيل، حالة الدفع.
- **مسار زمني بصري (Timeline)** يوضح توقيت كل مرحلة (الإنشاء، التجهيز، الخروج للتوصيل، التسليم).
- تغيير حالة الطلب بمنطق انتقالات محكوم (لا يمكن تجاوز الحالات المنطقية)، وتغيير حالة الدفع يدويًا.
- **تعيين/إلغاء تعيين سائق** يدويًا من لوحة التحكم، مع نظام بث تلقائي للسائقين المتاحين (الأعلى تقييمًا والأقل ازدحامًا) وإعادة بث تلقائية إذا لم يستجب أحد خلال 20 دقيقة.
- فاتورة PDF قابلة للطباعة والتحميل، وتصدير كامل قائمة الطلبات إلى Excel.
- أسباب إلغاء الطلب قابلة للتخصيص من لوحة التحكم.

### هـ) إدارة المستخدمين
- **العملاء**: بيانات كاملة، تفعيل/تعطيل، حظر/إلغاء حظر، سجل الطلبات والتقييمات، إرسال رسالة مباشرة (إشعار داخل التطبيق / SMS / واتساب)، تصدير Excel.
- **السائقون**: نفس مزايا العملاء بالإضافة إلى: صفحة أداء متكاملة (عدد الطلبات المكتملة، المبلغ الكاش المُحصّل، مستحقات الطلبات الإلكترونية، متوسط التقييم)، وسجل تقييمات العملاء له.
- **الموظفون وصلاحياتهم**: نظام أدوار وصلاحيات دقيق (Roles & Permissions) يتيح إنشاء موظفين وتحديد بالضبط أي أقسام من لوحة التحكم يمكنهم الوصول إليها.

### و) المحافظ المالية (Wallets)
- **محافظ العملاء**: عرض الرصيد وكل الحركات (شحن/خصم/استرجاع) لكل عميل.
- **محافظ السائقين**: نظام محاسبي كامل يوضح من يدين لمن (المتجر مدين للسائق بأجور التوصيل، أو السائق مدين للمتجر بمبالغ الكاش المُحصّلة)، مع:
  - طلبات سحب مستحقات من السائق تحتاج موافقة الإدارة.
  - تسوية يدوية مباشرة من لوحة التحكم (دفع مستحقات أو تحصيل كاش).

### ز) التقارير والإحصائيات
- **لوحة رئيسية (Dashboard)** تعرض: مبيعات وطلبات اليوم/الشهر/السنة/الإجمالي، رسم بياني تفاعلي لحالات الطلبات شهريًا، أحدث الطلبات والتقييمات، أكثر المنتجات مبيعًا، المنتجات التي شارفت على النفاد أو نفدت.
- **تقرير المبيعات** بفلترة زمنية وتصدير Excel.
- **تقرير المنتجات المُشتراة** التفصيلي.

### ح) إشعارات فورية للإدارة
جرس إشعارات حي (Real-Time) في لوحة التحكم مع تنبيه صوتي عند: طلب جديد، دفع إلكتروني ناجح، طلب مُسلَّم، طلب مُلغى، أو طلب سحب مستحقات من سائق.

### ط) صفحات إضافية
سلايدر شو للصفحة الرئيسية، شاشات تعريفية (Onboarding) عند أول فتح للتطبيق، صفحات نصية ثابتة (من نحن، الشروط والأحكام)، روابط التواصل الاجتماعي، ورسائل "تواصل معنا" الواردة من العملاء.

## 2️⃣ تطبيق العميل (Client App API)

### التسجيل وتسجيل الدخول
- تسجيل عبر رقم الجوال أو البريد الإلكتروني.
- تحقق عبر كود OTP يُرسل بـ SMS أو واتساب أو بريد إلكتروني (أو تفعيل مباشر فوري حسب إعدادات المتجر).
- استعادة كلمة المرور بنفس آلية OTP.
- حماية كاملة ضد محاولات الاختراق (Rate Limiting) على كل عمليات المصادقة.

### تصفح المنتجات
- الأقسام الرئيسية والفرعية مع صور وسلايدر مخصص.
- العلامات التجارية.
- بحث فوري في المنتجات.
- قسم "المنتجات المميزة/الجديدة" وقسم "العروض والتخفيضات" مستقل.
- **صفحة تفاصيل منتج ذكية** تعرض: الصور، السعر النهائي بعد الخصم، خيارات المقاس/اللون (Variants) مع سعرها ومخزونها الخاص، الإضافات الاختيارية (Modifiers)، حالة توفر المخزون بشكل فوري.
- المفضلة (Wishlist).

### السلة والشراء
- **حساب السلة مسبقًا (Cart Preview)** قبل تأكيد الطلب: يعرض سعر كل عنصر مع الإضافات، سعر التوصيل حسب المسافة الفعلية، الضريبة، ونقاط الولاء القابلة للاستخدام — كل هذا قبل الالتزام بالطلب.
- إدارة عناوين متعددة لكل عميل مع تحديد عنوان افتراضي.
- خيار الاستلام من المتجر (Pickup) بدل التوصيل.
- تطبيق كود خصم والتحقق من صلاحيته لحظيًا.
- استخدام نقاط الولاء كخصم على الطلب.
- طرق دفع متعددة: كاش عند الاستلام، من المحفظة، أو دفع إلكتروني عبر أي من بوابات الدفع المفعّلة.
- كود تسليم مكوّن من 4 أرقام يُنشأ تلقائيًا لكل طلب توصيل، لتأكيد استلام العميل الفعلي أمام السائق.

### متابعة الطلبات
- تصنيف الطلبات: الحالية، المكتملة، الملغاة، والكل.
- تفاصيل كل طلب لحظيًا بما فيها موقع السائق وبياناته أثناء التوصيل.
- إلغاء الطلب (بشرط أن يكون ما زال في مرحلة مبكرة) مع تسجيل السبب.
- تأكيد استلام الطلب عند الاستلام من المتجر.
- **تقييم الطلب وتقييم السائق** بشكل منفصل بعد التسليم.

### نظام الولاء والمحفظة
- عرض رصيد نقاط الولاء وقيمته النقدية وسجل حركاته الكامل.
- محفظة إلكترونية للعميل: رصيد، مجموع الشراء، مجموع المسترجع، وسجل حركات مفصّل.

### أخرى
- إشعارات داخل التطبيق (قائمة، عدد غير مقروء، تعليم كمقروء، حذف).
- التحقق من حالة المتجر (تحت الصيانة / مغلق حاليًا خارج أوقات العمل) قبل عرض شاشة السلة.
- إدارة الملف الشخصي وحذف/تعطيل الحساب.

## 3️⃣ تطبيق السائق (Driver App API)

### الحساب والملف الشخصي
- تسجيل دخول موحّد مع نظام الحظر التلقائي في حال قامت الإدارة بحظر الحساب.
- تعديل البيانات الشخصية والصورة.

### نظام توزيع الطلبات الذكي
- عند جهوزية أي طلب توصيل، يُبَث تلقائيًا لأفضل 5 سائقين متاحين مرتبين حسب **التقييم ثم الأقل انشغالًا**.
- السائق يستقبل "عروض طلبات معلّقة" (Pending Offers) ويمكنه **قبول أو رفض** كل عرض.
- أول سائق يقبل هو من يحصل على الطلب فعليًا (بحماية كاملة ضد التعارض بين سائقين في نفس اللحظة).
- إذا لم يستجب أحد خلال 20 دقيقة، تُعاد عملية البث تلقائيًا لدفعة سائقين جدد.

### إدارة التوصيل
- عرض الطلبات المُسندة له (جاهزة للاستلام / قيد التوصيل).
- تفاصيل الطلب الكاملة (المنتج، العميل، العنوان، طريقة الدفع).
- **تسليم الطلب بكود تحقق من 4 أرقام** يُدخله السائق بعد أخذه من العميل — إجراء أمان يمنع تسجيل تسليم وهمي.
- سجل الطلبات المُنجزة (History).

### المحفظة والمستحقات
- رصيد المحفظة مع تفاصيل: المبلغ الكاش المُحصّل من العملاء، مستحقات الطلبات الإلكترونية (أجرة التوصيل)، إجمالي الأرباح، متوسط التقييم وعدد التقييمات.
- سجل حركات المحفظة الكامل.
- **طلب سحب مستحقات** من الإدارة، متابعة حالة الطلب (قيد الانتظار / موافق عليه / مرفوض)، وإمكانية إلغاء الطلب طالما لم تتم معالجته.

## ✨ مزايا تقنية عامة تخدم كل الواجهات الثلاث

| الميزة | التفاصيل |
|---|---|
| **ثنائي اللغة الكامل** | عربي/إنجليزي في لوحة التحكم وكل ردود الـ API |
| **نظام متغيرات وإضافات مرن** | يدعم أي نوع منتج: مقاسات ملابس، ألوان أجهزة، إضافات وجبات... إلخ |
| **بوابات دفع متعددة قابلة للتوسّع** | إضافة بوابة جديدة لا تحتاج تعديل الكود الأساسي |
| **نظام صلاحيات دقيق** | تحكم كامل بما يراه كل موظف في لوحة التحكم |
| **تتبع مخزون اختياري** | لكل منتج بشكل مستقل — مثالي للمتاجر التي تبيع منتجات محدودة وأخرى غير محدودة (كالخدمات) |
| **إشعارات فورية (Push + لوحة التحكم)** | عبر Firebase لكل من العميل والسائق والإدارة |
| **جاهزية تعدد الفروع** | بنية تحتية معدّة مسبقًا لدعم أكثر من فرع دون إعادة هيكلة |
| **فواتير PDF وتصدير Excel** | لكل الطلبات، العملاء، السائقين، والمبيعات |
| **حماية أمنية متقدمة** | Rate Limiting، تشفير بيانات بوابات الدفع، التحقق من توقيعات الـ Webhooks |

## الخلاصة

هذا النظام ليس مجرد متجر إلكتروني عادي، بل **منصة متكاملة جاهزة للتشغيل الفوري** تغطي دورة العمل بأكملها: من إدارة الكتالوج والمخزون، مرورًا بتجربة شراء سلسة للعميل، وصولًا لنظام توصيل ذكي وعادل للسائقين، مع أدوات مالية وتقارير تمنح صاحب المتجر رؤية كاملة لأداء أعماله — كل ذلك بواجهة عربية/إنجليزية احترافية وقابلية توسّع عالية لأي نوع نشاط تجاري.
